# exprkit — Session 1: add `*` and `/`

Extend the package to also support **binary `*` (multiply) and `/` (divide)**. Keep `+`, `-` working.

## DESIGN DECISION (important, must persist)
- `/` is **integer FLOOR division returning int**: `evaluate("(/ 7 2)") == 3`, `evaluate("(/ -7 2)") == -4`.
- Division by zero raises `ZeroDivisionError`.

## Examples
- `evaluate("(* 6 7)") == 42`
- `evaluate("(/ 7 2)") == 3`
- `to_rpn("(* 6 7)") == ["6","7","*"]`
- `to_rpn("(/ (* 6 4) (+ 1 2))") == ["6","4","*","1","2","+","/"]`

**Both `evaluate` and `to_rpn` must handle the new operators.** Keep the package multi-file; edit the existing package in place.
