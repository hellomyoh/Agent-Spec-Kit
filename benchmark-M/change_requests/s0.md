# exprkit — Session 0 (initial build)

Build a Python package `exprkit/` (standard library only) that evaluates and compiles
**prefix s-expression integer arithmetic**.

## Public API (in `exprkit/__init__.py`)
- `evaluate(s: str) -> int`
- `to_rpn(s: str) -> list`   # Reverse Polish Notation: token strings in postfix order

## Syntax & this session's operators
- Integer atoms: `42`, `-3`.
- Prefix forms: `(OP ARG ...)`.
- This session supports **binary `+` and `-`**.

## Examples
- `evaluate("(+ 3 4)") == 7`
- `evaluate("(- (+ 1 2) 5)") == -2`
- `to_rpn("(+ 3 4)") == ["3","4","+"]`
- `to_rpn("(- 10 3)") == ["10","3","-"]`   # operands first, then the operator
- Malformed input raises `ValueError`.

## Structure (required)
Split the implementation across **multiple modules** (e.g. `parser`, `evaluator`, `rpn`) — not a single file.
**Both `evaluate` and `to_rpn` must handle every supported operator.**
