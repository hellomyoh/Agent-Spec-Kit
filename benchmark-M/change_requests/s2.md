# exprkit — Session 2: add unary `neg`

Extend the package to support the **unary operator `neg`**: `(neg X)` negates `X`. It takes **exactly one** argument.

## Examples
- `evaluate("(neg 5)") == -5`
- `evaluate("(neg (- 2 9))") == 7`
- `to_rpn("(neg (+ 1 2))") == ["1","2","+","neg"]`   # operand tokens, then `neg`

**Both `evaluate` and `to_rpn` must handle `neg`, and all prior operators (`+ - * /`) must keep working in BOTH.** Edit the existing package in place.
