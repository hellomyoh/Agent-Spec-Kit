# exprkit — Session 3: add `pow`

Extend the package to support **binary `pow`**: `(pow A B)` = A raised to the power B.

## Examples
- `evaluate("(pow 2 5)") == 32`
- `evaluate("(pow (+ 1 1) (- 4 1))") == 8`
- `to_rpn("(pow 2 3)") == ["2","3","pow"]`

**Both `evaluate` and `to_rpn` must handle `pow`, and all prior operators (`+ - * / neg`) must keep working in BOTH.** Edit the existing package in place.
