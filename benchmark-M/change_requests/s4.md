# exprkit — Session 4: add comparisons `lt`, `gt`, `eq`

Extend the package to support **binary comparison operators** `lt`, `gt`, `eq`, each returning `1` (true) or `0` (false).

## Examples
- `evaluate("(lt 3 4)") == 1`, `evaluate("(gt 3 4)") == 0`, `evaluate("(eq 4 4)") == 1`
- `evaluate("(eq (* 2 3) (+ 5 1))") == 1`
- `to_rpn("(lt 3 4)") == ["3","4","lt"]`

**Both `evaluate` and `to_rpn` must handle `lt`,`gt`,`eq`, and all prior operators (`+ - * / neg pow`) must keep working in BOTH.** Edit the existing package in place.
