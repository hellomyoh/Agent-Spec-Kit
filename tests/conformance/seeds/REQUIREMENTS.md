# REQUIREMENTS — 링크 단축 서비스 (파일럿 시드)

> L2 적합성 파일럿용 최소 요구사항. 작지만 횡단 계약(인증·데이터모델·에러포맷)이 생기도록 구성했습니다.

## 1. 프로젝트 개요

짧은 URL을 발급하고, 단축 코드로 원본 URL로 리다이렉트하는 작은 HTTP 서비스.

## 2. 대상 사용자

API로 링크를 만드는 개발자 / 단축 링크를 클릭하는 일반 방문자.

## 3. 핵심 기능 (MVP)

1. **링크 생성** — 원본 URL을 받아 단축 코드를 발급(`POST /links`). API Key 필요.
2. **리다이렉트** — 단축 코드로 접근 시 원본 URL로 302 리다이렉트(`GET /{code}`). 인증 불필요.
3. **링크 목록** — 내가 만든 링크 목록 조회(`GET /links`). API Key 필요.

## 4. 후순위 (post-MVP)

- 클릭 수 집계 / 만료 시간 / 관리자 토큰 회수.

## 5. 데이터

- link: `code`(단축 코드), `url`(원본), `owner`(API Key 소유자), `created_at`.

## 6. 외부 연동

없음 (로컬 저장소/인메모리 또는 단일 파일 DB로 충분).

## 7. 인증 / 권한

- API Key 헤더 기반(`X-API-Key`). 키 발급 방식의 세부는 `[AI 위임]`.

## 8. 횡단(아키텍처) 기준

- 공통 에러 포맷: `{ "error": { "code": ..., "message": ... } }`.
- 네이밍/코드 스타일/저장소 선택의 세부는 `[AI 위임]`.

## 9. 테스트 / QA

- 각 기능에 자동 테스트(정상 + 인증 실패 + 없는 코드). 테스트는 실제 실행으로 통과 확인.

## 10. 운영 / 배포

- 로컬 실행이면 충분. 배포 제약 없음.

## 산출물 작성 언어

한국어 (코드 식별자·API 경로·commit 메시지는 영어 유지).
